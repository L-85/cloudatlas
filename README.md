# 云迹 CLOUD ATLAS 3.0.4

**云朵探索、个人拍摄归档与数字收藏平台**  
口号：收藏天空的每一种模样。

## 运行方式

本项目使用原生 **HTML + CSS + JavaScript**，无需安装 Node.js 或数据库。

1. 解压项目 ZIP。
2. 进入 `cloudatlas` 文件夹。
3. Windows 用户优先双击 `start.bat`。如果电脑安装 Python，会启动本地静态服务器并打开浏览器。
4. 建议使用最新版 Chrome 或 Edge，并保持联网以加载公开数据集图片、摄影图片和在线字体。

## 2.1.4 最终视觉与交互修订

## 2.1.1 本轮改版

## 当前功能

- 首页、每日云朵推荐、功能入口和十种云属预览
- 云朵探索：关键词搜索、云型/来源筛选、分页式读取公开数据集
- 云朵图鉴：WMO 十种云属基础介绍
- **我的云图：** 多图上传、拖放上传、逐张分类、编辑分类、下载原图、删除照片
- 我的收藏：收藏状态保存在当前浏览器
- 天空明信片：实时预览、三种版式、保存明信片墙和 PNG 导出
- 色彩实验室：Canvas 图片像素取色；跨域受限时回退到素材参考色卡
- 云朵挑战：覆盖十种云属的识别题与答题结果
- 我的天空档案：根据本地收藏、上传图片和明信片生成统计
- 数据与素材来源：公开数据集统计、样本入口、摄影师与来源记录

## 个人照片的分类说明

- 可选择「待分类」，不确定云型时不要勉强选择。
- 已提供十种云属选项：卷云、卷积云、卷层云、高积云、高层云、雨层云、层积云、层云、积云和积雨云。
- 个人照片的云型由用户自行选择或修改；当前版本不宣称自动 AI 识别云型。
- 每张照片还可以记录心情、日期、地点和一句备注。

## 数据与隐私

- 公开数据集样本与用户个人照片分开标记。
- 用户上传的图片和分类信息存储在浏览器 IndexedDB，不上传到云端服务器；本版本不提供账号登录、跨设备同步或云端备份。
- 用户可以在「我的云图」逐张下载原图。清除浏览器网站数据前，请先保存需要保留的照片。
- CCAiM-CloudsDataset 页面列出 971 条图像记录、10 种云属。项目预载首批 100 张样本，并在用户主动操作时通过 Hugging Face Dataset Viewer 分批读取后续样本；不把约 3.09 GB 的完整数据集打包进 ZIP。
- WMO International Cloud Atlas 用作云属分类知识参考。Pexels 摄影作品仅作视觉欣赏，不能仅凭一张照片作正式气象判定。

## 技术说明

- HTML5：页面结构与语义化内容
- CSS3：响应式布局、卡片、渐变、动效与视觉规范
- JavaScript：页面切换、搜索筛选、收藏、上传、分类、明信片、问答、统计和 Canvas 色彩提取
- IndexedDB：存储用户上传的图片 Blob 和分类元数据
- LocalStorage：保存收藏与天空明信片文本数据
- Canvas API：从允许跨域读取的图片中提取主色

这是课程项目的前端应用原型，不含真实账号系统、云端同步或服务器端数据库。
